# Benchmark structure

Each benchmark program is stored under `benchmark/{program}/` and contains the following files:

## Required files

**`c_build.sh`** — Build script for the C program. Compiles the source with Clang using the following tools.
- `-finstrument-functions -g -gdwarf-4` flags: These are required for golden flow extraction.
- `bear` or CMake's `CMAKE_EXPORT_COMPILE_COMMANDS`: These generate `compile_commands.json` which is required for parsing analysis.

**`base_test.sh`** — Original test script for the C program. This is the input to Step 1 (reformat test cases) and is not used directly by the pipeline after reformatting. See [docs/reformat-testcases.md](docs/reformat-testcases.md) for details on how this is transformed.

**`targets.txt`** — Specifies the entry point functions for translation. Each line follows the format:

```
function_name:path/to/file.c:start_line:end_line
```
For example: `main:src/zopfli/zopfli_bin.c:144:219`

## Generated files

**`run_test.sh`** — Reformatted test script generated by Step 1. Each test case is isolated with tracing instrumentation and standardized pass/fail reporting.

**`compile_commands.json`** — Compilation database generated by `c_build.sh`, used by the C parser for static analysis.
